# Legacy launch scripts

Shell scripts from the System Detection / Custos security monitor, moved here
from the repository root. Kept for reference, not maintained: several hard-code
paths and environments of old development machines. They expect to be run from
the repository root (`scripts/legacy/<name>.sh`); `launch-system-monitor.sh`
changes there itself.

Current commands are in `CLAUDE.md` and `package.json` (`pnpm tauri:dev`,
`pnpm tauri:dev:monitor`).
